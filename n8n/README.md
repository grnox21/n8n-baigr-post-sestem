# نشرة الذكاء الاصطناعي اليومية → تليجرام

سيستم يرسل لك كل يوم **الساعة 9:00 صباحاً بتوقيت الرياض** رسالة تليجرام مفصّلة
فيها أحدث أخبار الذكاء الاصطناعي وكل تحديث جديد على Claude و ChatGPT و Gemini
والأدوات التي تستخدمها، مع أداة أو موقع جديد يستحق التجربة كل يوم.

- **الـ workflow المنشور:** https://grnoxpickup.app.n8n.cloud/workflow/oY2QdPxmgZ3KDkBl
- **المصدر:** [`ai-daily-news-telegram.workflow.ts`](./ai-daily-news-telegram.workflow.ts)

الـ workflow **غير مفعّل** حالياً. ينقصه بوت تليجرام مستقل و `Chat ID` (الخطوات أدناه).

---

## كيف يشتغل

```
9:00 ص (Asia/Riyadh)
   ↓
Feed Sources ............ 19 مصدر RSS/Atom
   ↓
Read Feed ............... يقرأ كل مصدر (المصدر الساقط يُتجاهل ولا يوقف التشغيل)
   ↓
Normalize And Filter .... آخر 30 ساعة، تنظيف HTML، ترتيب بالأحدث،
                          8 عناصر كحد أقصى لكل مصدر، 110 إجمالاً
   ↓
Drop Already Sent ....... يحجب أي خبر أُرسل لك سابقاً (ذاكرة 20 ألف رابط)
   ↓
Build Digest Brief ...... يبني ملف العناصر الخام + تاريخ اليوم بالعربية
   ↓
Write Arabic Digest ..... Claude (claude-sonnet-5) + Web Search
   ↓
Split For Telegram ...... تنظيف النص، تهريب HTML، تقسيم لرسائل ≤ 3500 حرف
   ↓
Send Digest On Telegram
```

## خطوات التشغيل

النشرة تُرسل من **بوت مستقل** غير البوت المستخدم في مشاريعك الأخرى.

### 1) أنشئ البوت

في تليجرام افتح **@BotFather** وأرسل:

```
/newbot
```

اختر اسم عرض (مثلاً `AI Daily Digest`) ثم username ينتهي بـ `bot`. يرد عليك
بتوكن شكله `8123456789:AAH...` — احتفظ به.

### 2) أضف الاعتماد في n8n

`Credentials` ← `New` ← **Telegram API**

- الاسم: `AI News Bot`
- Access Token: التوكن من BotFather

ثم افتح عقدة `Send Digest On Telegram` واختر `AI News Bot` من خانة Credential.

> العقدة ما زالت مربوطة بـ `Telegram account` القديم — n8n لا يسمح بربط اعتماد
> غير موجود، فالتبديل يدوي. سوّه قبل التفعيل وإلا أُرسلت النشرة من البوت القديم.

### 3) اختر وجهة النشرة

**أ) محادثة خاصة مع البوت — الأسرع**

1. افتح محادثة مع بوتك الجديد وأرسل `/start` مرة واحدة. هذه الخطوة إلزامية:
   تليجرام يمنع البوت من بدء محادثة معك، وبدونها يرجع `chat not found`.
2. خذ رقمك من **@get_id_bot** وضعه في حقل `Chat ID`.

> ⚠️ تأكد أن الحقل يحتوي الرقم فقط بلا مسافة قبله أو بعده. مسافة واحدة زائدة
> تجعل تليجرام يرجع `400 Bad Request: chat not found` — وهي رسالة مضللة توحي
> بأن المشكلة في المعرّف نفسه.

**ب) قناة خاصة — الأنظف لأرشيف يومي**

1. أنشئ قناة **Private** جديدة.
2. أضف البوت فيها كـ **Admin** مع صلاحية **Post Messages**.
3. خذ معرّف القناة من **@get_id_bot** — رقم سالب يبدأ بـ `-100` — وضعه في
   `Chat ID`.

القناة تخلي النشرة في مكان مستقل تماماً، وتقدر تثبّت رسائل وتبحث في الأرشيف
وتضيف أشخاصاً لاحقاً.

### 4) وجهات إضافية (اختياري)

النشرة بتقدر تروح لأكتر من محادثة أو قناة. كل الوجهات بقائمة `RECIPIENTS`
بأول عقدة **Split For Telegram**:

```js
const RECIPIENTS = [
  '1038608008',              // 1) محادثتك الخاصة مع البوت
  'حط_رقم_الشخص_التاني',   // 2) شخص تاني — بدّل هالنص برقمو
  'حط_معرف_القناة',        // 3) قناة النشرة — رقم سالب بيبلّش بـ -100
];
```

**لإضافة شخص:** يفتح محادثة مع البوت ويبعت `/start` (إلزامي)، ثم يأخذ رقمو من
**@get_id_bot**.

**لإنشاء قناة مستقلة للنشرة** — البوتات ما بتقدر تنشئ قنوات، فلازم تعملها إنت:

1. تليجرام ← قلم الكتابة ✏️ ← **New Channel**
2. اختر اسماً ← **Private** ← تخطّى إضافة الأعضاء
3. افتح القناة ← اضغط اسمها فوق ← **Administrators** ← **Add Admin** ←
   دوّر على بوتك ← فعّل **Post Messages** ← Save
4. انشر أي رسالة بالقناة، ثم اضغط عليها ← **Forward** ← ابعتها لـ **@get_id_bot**
5. بيرد عليك بمعرّف القناة — رقم سالب يبلّش بـ `-100`
6. حط الرقم مكان `حط_معرف_القناة`

> ⚠️ بدون خطوة 3 (البوت Admin بصلاحية Post Messages) تليجرام بيرفض النشر.

> أي خانة لسا نص تذكيري بتنتجاهل تلقائياً، فما بتكسر الإرسال لبقية الوجهات.

حقل `Chat ID` بعقدة الإرسال صار تعبيراً يقرأ من القائمة، فما لازم تلمسو.

### 5) جرّب ثم فعّل

1. `Execute workflow` يدوياً — لازم تصلك الرسالة على تليجرام.
2. افتح مخرجات `Build Digest Brief` وانظر `deadFeedList` — احذف من
   `Feed Sources` أي مصدر يفشل باستمرار.
3. فعّل الـ workflow من زر **Active**.

## التخصيص

| تريد تغيير | المكان |
|---|---|
| الساعة | عقدة `Daily 09:00 Riyadh` ← cron `0 9 * * *` (الرقم 9 هو الساعة) |
| المصادر | عقدة `Feed Sources` — أضف/احذف من المصفوفة (لا تتجاوز 20) |
| أقسام النشرة أو طولها أو أسلوبها | عقدة `Write Arabic Digest` ← Options ← System |
| النافذة الزمنية أو عدد العناصر | عقدة `Normalize And Filter` — `WINDOW_HOURS` و `MAX_ITEMS` و `PER_SOURCE` |
| النموذج | عقدة `Write Arabic Digest` ← Model |
| حد طول الرسالة | عقدة `Split For Telegram` ← `LIMIT` |
| مين بتوصلو النشرة | عقدة `Split For Telegram` ← قائمة `RECIPIENTS` بأول الكود |
| البوت المُرسِل | عقدة `Send Digest On Telegram` ← Credential |

## ملاحظات تشغيلية

- **مدة التشغيل:** حوالي 70 ثانية. حد التنفيذ على المنصة **180 ثانية** ولا يمكن
  رفعه، فالهامش ضيق.
- **⚠️ أهم سبب لانقطاع التشغيل: قراءة المصادر.** عقدة `Read Feed` تقرأ المصادر
  **واحداً وراء الآخر**، فمصدر واحد بطيء أو حاجب يعلّق الطابور ويأكل الـ 180
  ثانية كلها قبل أن يصل الدور إلى Claude. لهذا:
  - إعادة المحاولة **معطّلة** على `Read Feed` — كانت تضاعف زمن أي مصدر معلّق.
  - حُذفت Reddit و Product Hunt و MIT Tech Review لأنها تحجب أو تُبطئ عناوين
    السحابة. لا ترجّعها.
  - لا تتجاوز 20 مصدراً في `Feed Sources`.
  - إذا انقطع التشغيل مرة أخرى، افتح آخر execution وانظر أي عقدة كانت آخر
    واحدة نفّذت: إن كانت `Feed Sources` فالمشكلة في المصادر، وإن كانت
    `Build Digest Brief` فالمشكلة في Claude وعندها قلّل `maxUses` من 3 إلى 2.
- **`temperature` ممنوع:** موديل `claude-sonnet-5` يرفضه ويرجع خطأ 400. لا تضفه
  في خيارات العقدة.
- **تهريب HTML:** تليجرام في وضع HTML يقبل وسوماً محدودة، وأي وسم غير مغلق يجعله
  يرفض الرسالة كاملة بخطأ 400. عقدة `Split For Telegram` تهرّب كل الرموز ثم تعيد
  `<b>` و `<i>` و `<code>` فقط، وتوازن الوسوم في كل رسالة على حدة.
- **`alwaysOutputData`** مفعّل على `Drop Already Sent` عمداً، حتى تصلك رسالة
  يومية حتى لو لم يكن هناك أي خبر جديد.
- **التوقيت** مضبوط على مستوى الـ workflow (`Asia/Riyadh`) وليس داخل عقدة
  الجدولة، فلا تعتمد على توقيت الخادم.
- **الكلفة اليومية:** استدعاء واحد لـ Claude Sonnet مع حتى 4 عمليات بحث.
