# نشرة الذكاء الاصطناعي اليومية → واتساب

سيستم يرسل لك كل يوم **الساعة 9:00 صباحاً بتوقيت الرياض** رسالة واتساب مفصّلة
فيها أحدث أخبار الذكاء الاصطناعي وكل تحديث جديد على Claude و ChatGPT و Gemini
والأدوات التي تستخدمها، مع أداة أو موقع جديد يستحق التجربة كل يوم.

- **الـ workflow المنشور:** https://grnoxpickup.app.n8n.cloud/workflow/oY2QdPxmgZ3KDkBl
- **المصدر:** [`ai-daily-news-whatsapp.workflow.ts`](./ai-daily-news-whatsapp.workflow.ts)

الـ workflow **غير مفعّل** حالياً. فعّله بعد إتمام خطوات إعداد واتساب أدناه.

---

## كيف يشتغل

```
9:00 ص (Asia/Riyadh)
   ↓
Feed Sources ........... 22 مصدر RSS/Atom
   ↓
Read Feed .............. يقرأ كل مصدر (المصدر الساقط يُتجاهل ولا يوقف التشغيل)
   ↓
Normalize And Filter ... آخر 30 ساعة، تنظيف HTML، ترتيب بالأحدث،
                         8 عناصر كحد أقصى لكل مصدر، 110 إجمالاً
   ↓
Drop Already Sent ...... يحجب أي خبر أُرسل لك سابقاً (ذاكرة 20 ألف رابط)
   ↓
Build Digest Brief ..... يبني ملف العناصر الخام + تاريخ اليوم بالعربية
   ↓
Write Arabic Digest .... Claude (claude-sonnet-5) + Web Search
   ↓
Split For WhatsApp ..... تنظيف النص وتقسيمه لرسائل ≤ 3400 حرف
   ↓
Send Digest On WhatsApp
   └─ عند الفشل → Fallback Template Opener (قالب Meta معتمد)
```

## خطوات التشغيل

### 1) اعتماد واتساب (مطلوب)

عقدتا الإرسال تحتاجان اعتماد **WhatsApp API** — وهو غير `whatsAppTriggerApi`
الموجود في الحساب حالياً، لأن ذاك للاستقبال فقط.

من n8n: `Credentials` ← `New` ← `WhatsApp API`، وأدخل:

- **Access Token** — من Meta for Developers ← تطبيقك ← WhatsApp ← API Setup
- **Business Account ID** — من نفس الصفحة

### 2) املأ الحقول

| العقدة | الحقل | القيمة |
|---|---|---|
| Send Digest On WhatsApp | Phone Number ID | من Meta ← WhatsApp ← API Setup |
| Send Digest On WhatsApp | Recipient Phone Number | رقمك مع مفتاح الدولة بلا `+` ولا مسافات، مثل `9665XXXXXXXX` |
| Fallback Template Opener | Phone Number ID | نفس القيمة |
| Fallback Template Opener | Recipient Phone Number | نفس القيمة |
| Fallback Template Opener | Template | اسم القالب المعتمد (الخطوة 3) |

### 3) قيد نافذة الـ 24 ساعة — اقرأ هذا

Meta لا تسمح بإرسال **رسالة نصية حرة** إلا داخل نافذة 24 ساعة تبدأ من آخر
رسالة **ترسلها أنت** لرقم البوت. خارج النافذة يُرفض الإرسال بالخطأ `131047`.
هذا قيد من Meta وليس مشكلة في الـ workflow.

أمامك خياران:

**أ) الأسهل — أبقِ النافذة مفتوحة**
أرسل أي رسالة لرقم البوت مرة كل يوم (قبل التاسعة صباحاً). النشرة تصلك كاملة
كنص حر بكل التنسيق والروابط.

**ب) قالب معتمد — يعمل بلا تدخل يومي**
أنشئ في Meta Business Manager قالباً:

- الاسم: `ai_daily_digest`
- اللغة: `ar`
- الفئة: Utility
- الجسم: `نشرة الذكاء الاصطناعي — {{1}}` ثم سطر جديد `{{2}}`
- أضف زر **Quick Reply** نصه مثلاً «التفاصيل»

ضغطك على الزر يفتح نافذة الـ 24 ساعة فوراً. عقدة `Fallback Template Opener`
تملأ `{{1}}` بالتاريخ و `{{2}}` بملخص سطر واحد (≤ 700 حرف بلا أسطر جديدة،
لأن Meta ترفض الأسطر الجديدة داخل معاملات القوالب).

### 4) جرّب ثم فعّل

1. `Execute workflow` يدوياً وراقب المخرجات.
2. افتح مخرجات `Build Digest Brief` وانظر `deadFeedList` — احذف من
   `Feed Sources` أي مصدر يفشل باستمرار.
3. لما تصلك الرسالة على واتساب، فعّل الـ workflow من زر **Active**.

## التخصيص

| تريد تغيير | المكان |
|---|---|
| الساعة | عقدة `Daily 09:00 Riyadh` ← cron `0 9 * * *` (الرقم 9 هو الساعة) |
| المصادر | عقدة `Feed Sources` — أضف/احذف من المصفوفة |
| أقسام النشرة أو طولها أو أسلوبها | عقدة `Write Arabic Digest` ← Options ← System |
| النافذة الزمنية أو عدد العناصر | عقدة `Normalize And Filter` — `WINDOW_HOURS` و `MAX_ITEMS` و `PER_SOURCE` |
| النموذج | عقدة `Write Arabic Digest` ← Model |
| حد طول الرسالة | عقدة `Split For WhatsApp` ← `LIMIT` |

## ملاحظات تشغيلية

- **مدة التشغيل:** حوالي 85 ثانية (منها ~70 ثانية لـ Claude مع البحث). حد
  التنفيذ على المنصة 180 ثانية. إذا صادفت انتهاء مهلة، قلّل `maxUses` في خيارات
  عقدة Claude من 4 إلى 2.
- **`temperature` ممنوع:** موديل `claude-sonnet-5` يرفضه ويرجع خطأ 400. لا تضفه
  في خيارات العقدة.
- **`alwaysOutputData`** مفعّل على `Drop Already Sent` عمداً، حتى تصلك رسالة
  يومية حتى لو لم يكن هناك أي خبر جديد.
- **التوقيت** مضبوط على مستوى الـ workflow (`Asia/Riyadh`) وليس داخل عقدة
  الجدولة، فلا تعتمد على توقيت الخادم.
- **الكلفة اليومية:** استدعاء واحد لـ Claude Sonnet مع حتى 4 عمليات بحث.
